# mohs_surgeons
Running the merge_mohs_data.R script creates the Final_Mohs_Billing.csv and mohs_billing_all.csv files already in the data folder. It requires all of the other files in the data folder. 

Running the get_surgeon_demographic_data.R script will then create all of the dataframes and csv files required to run the other scripts. It requires the Final_Mohs_Billing.csv file in the data folder.
